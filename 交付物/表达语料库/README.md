## 1. 定位与双用途

- **产品用**：条目由构建器 `_test/wit_quotes_build.py` 编译为 `src/data/wit-quotes.js`；`chat-agent.js` 在每轮对话时按「当前情绪 + 话题」匹配候选（≤5 条）注入系统提示词，模型按引用规则（§5）自行判断是否引用。
- **对话用**：人工轮研究/审读时，用条目编号（如 `[[QTE-CL-001]]`）讨论表达质量与适配。
- **边界**：本库是「表达素材」不是「事实依据」——引用语句不承担事实断言责任；考据信息（出处/误传）只决定"能不能标归属"。

## 2. 出处可信度五级制（与心理学知识库同构、语义不同）

| 级 | 名称 | 判据 | 使用规则 |
|---|---|---|---|
| A | 确证 | 原典/全集/权威库可查证出处与原文（如《唐多令》原文、笛卡尔《方法论》） | 可自然引入并可标出处 |
| B | 可溯 | 有明确首发载体可查（歌曲/电影/书/访谈/公开演讲） | 可引用；提出处以作品名为准 |
| C | 存疑 | 广泛流传但归属有争议（如误挂在鲁迅/某名人名下） | 可引用；**禁止标注归属**，用法栏须写明"不得指名" |
| D | 流传 | 网络流行语/热句/梗，无权威出处 | 可引用（"有句话说""网上常有人讲"式引入）；禁标归属 |
| E | 未核 | 文字准确性与出处均无法确认 | **不入产品件**（构建期排除并计数），下一轮优先核实或升级 |

定级纪律：

1. **按句定级**，不按篇定级。
2. A/B 级须写可核对来源（规范的文献/作品引文）；C 级须写明"误传或存疑"的具体情形。
3. **禁止**：A 级无实据；**C 级冒充 A（给误传句标上名人——本库最严重的错误）**；编造出处。

## 3. 条目卡模板（字段与行式固定，便于机器提取）

字段行一律 `- 字段名：值`（**全角冒号**），每张卡在篇章文件中按下面行式书写：

```markdown
### 条目 QTE-CL-001｜欲买桂花同载酒
- 可信度：A
- 出处：刘过《唐多令·芦叶满汀洲》（南宋）
- 适用情绪：通用
- 适用场景：陪伴、共情
- 用法：怀念旧友/感慨物是人非时作共鸣引子；先接住用户的失落，再轻引半句即可，忌整句背诵。
- 句面：欲买桂花同载酒，终不似，少年游。
- 风险注记：无
- 入库：2026-10-12 · 第1轮
```

字段说明：

- **适用情绪**：`joy/sadness/anger/fear/calm/love` 中选（顿号分隔可多个），无特定情绪倾向写 `通用`。
- **适用场景**：从 `共情/安抚/鼓励/解释/开解/庆祝/自我接纳/陪伴` 中选（顿号分隔可多个）。
- **用法**：什么时候用、怎么自然带出、有什么禁忌（一句话写清，禁含糊）。
- **适配提示**（r171 新增**可选**列）：≤34 字的触发子句，形如「用户…时」。产品注入时每轮只带 1-2 条候选的适配条件，
  构建器按三级取：**① 本列直写 → ② 从「用法」首句压缩（去掉（）补语，取到第一个「时」为止）→ ③ 回落场景标签**。
  为什么要这一列：派生压不出来的时候（实测 174 条里 26 条，其中 `04-哲学思辨` 整卷 20 条），说明卡面把「何时用」
  写在了后半句——那要么改写法把触发条件提到句首，要么直写本列。**只有这一列能把人工判断无损交给模型**，
  截断派生会咬掉半句、比弱信号更误导。写了本列但值为空 ⇒ 构建期报错（不许用空位假装修过卡）。
- **句面**：原文全文（引用必须原样，禁改写）。
- **风险注记**：争议/误传/讽刺原义/使用禁区；无则写 `无`。讽刺原义素材（如"世界上最小的提琴"）必须在此栏写明原义与被改用的口径。

更正规则：改动既有条目内容时在该卡末尾追加 `- 更正：<日期> 原值→新值（原因）`，不静默改写。

## 4. 编号与篇章

- 编号：`QTE-<篇码>-<三位序号>`。篇码：`CL` 文言古句与古诗词 ｜ `MS` 名家名句（中外作家/思想家/科学家/艺术家） ｜ `NET` 网络热句与流行文化（热句/歌词/影视台词/梗） ｜ `PH` 哲学思辨。
- 取号前先查 `索引.md` 与各篇文件，取未占用号；一个句子只入一条。
- 关联：卡内可用 `[[编号]]` 互引（如"同义互补""反义对照"）。

## 5. 产品侧引用规则（口径；最终实现以 `src/data/emotion-strategy.js` 为准）

1. **候选只是弹药**：语境不合时零引用——宁可不说，不许硬贴。
2. **每轮最多自然引用 1 句**（含半句化用）。
3. **引用必须接住上文**：先回应情绪/话题，再顺势带出；禁止开场就甩名言。
4. **引用是调味不是主菜**：回复主体仍是个性化共情，引用不得挤占主体。
5. **C/D 级禁标归属**：用"有句话""网上常有人讲"式引入；A/B 级可提出处（以作品名为主）。
6. **危机轮不引用**（危机走独立转介分支）；用户强烈情绪倾诉时优先接情绪，可放弃引用。
7. **原样引用**：不改写句面、不拼接两条以上、不编造出处。

## 6. 迭代机制与分工

每轮固定步骤：① 定选题与分篇 → ② 联网检索 + 考据（出处核验）→ ③ 按模板产条目并定级 → ④ 核对审读（格式/来源/争议/适配五维）→ ⑤ 构建器编译 + 产品注入验证。

- 研究员按篇分工（每轮一名研究员负责一篇，写面隔离）；审读员统查全库。
- `README.md` 只由人工轮修订，研究员与审读员禁改。

## 7. 红线

- 查不到来源 → 只能 D 级（流传）或 E 级并写明缺口，**不许硬编**。
- **讽刺/贬损原义的素材一律不得按原义使用**；若收录须按正面诠释改写口径并写明"只许共鸣不许嘲讽"。
- 不收录攻击性、歧视性、宿命论、鼓励极端行为的语句。
- 文件统一 UTF-8 + LF；本库只服务情绪陪伴场景，不构成医疗/心理治疗建议。
