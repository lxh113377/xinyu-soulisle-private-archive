## 2. 逐项差距说明（自家运行时，注入五类）

判据 `_test/fault_injection_check.py`：Playwright 路由拦截 `/api/chat`，五模式各跑一遍，
每模式记录 `hit_count`（注入是否真打到通道）。

| # | 注入 | 修前实测行为 | 修后 |
|---|---|---|---|
| F1 | HTTP 500 + 非 JSON 体 | 气泡正确写"大模型暂不可用"，**但状态徽章仍写「● 在线 AI」** | ✅ 徽章同帧翻为「● 大模型暂不可用（已降级本机模板）」 |
| F2 | 200 + 网关 HTML（非 JSON） | 同上徽章说谎 | ✅ 一致降级，未捕获异常 0 |
| F3 | `connectionrefused` 断连 | 徽章滞留在线态 | ✅ 翻面，且输入框未卡死 |
| F4 | **黑洞挂起**（accept 但不响应） | **60.6 s** 才兜底（`LLM_TIMEOUT_MS=60000`） | ✅ 15 s 熔断 + 兜底总耗时 30.2 s ≤ 35 s 预算 |
| F5 | 恢复正常上游 | —— | ✅ 下一轮自动回到在线态，`llmBad` 复位 |

**差距的本质**：不是"没有降级"，而是**降级了却说没降级**——界面同时存在两个真相源（气泡说真话、
徽章说假话）。这类缺陷在只做正向路径的套件里永远不红，必须注入才现形。
