## 3. 七维逐项差距

### 3.1 功能模块覆盖
- **消除**：情绪识别后端化（本轮）。前端现在可在后端可用时以后端为准，不可用时无痕回落，且**界面如实标注来源**。
- **仍在**：语义/向量记忆（8/14 家有同族能力）、i18n（3/14）、插件式扩展（判定为不做）。
- **反超项（可写进答辩）**：危机转介 0/14；可现场复跑的 73 条情绪评测 + JS↔Java 逐项全等 0/14；逐句情绪着色的 3D 星雾 + 刷新重放 无同构。

### 3.2 技术架构与实现方式
- v2 结论复核成立：与 LobeChat（Next.js + 构建器）**不是同一条路线**，是取舍不是缺陷（决策 #1/#2 五要素在档）。
- **本轮补的恰恰是"零构建路线的自找盲区"**：没有 lockfile ⇒ 用 `_test/vendor-manifest.json` 承担"谁是什么版本、哈希多少、上游到哪"的职责；没有 dependabot ⇒ 用 `--check-upstream` 手动/复赛节点触发。这是**按本项目形态移植抽象形状**，不是抄工具。
- 前端 `app.js` 469 行仍是单体编排（对标差距，计划内）。

### 3.3 性能表现
- **实测无退化**：gsap 3.12.5 → 3.15.0 后 `browser_check` / `lightshow_check` / `pixel_dual_check` 三套件 rc=0；首屏关键路径 819,767 B（预算 858,752 B）。
- **新增守卫**：体积表此前漏登记 `src/data/emotion-strategy.js`（4,720 B）且**新文件会静默绕过预算** ⇒ 现"漏登记即红"，`--selftest` 两条判据同时自证。
- **诚实登记未修**：`tick()` 仍逐粒子 CPU 着色；真机（iOS Safari / Android）帧率 **❌未实测**，headless 数字不作为性能结论依据（v2 同口径）。

### 3.4 可扩展性
- 加一类情绪 = 改两个纯数据文件（词表 + 策略表），代码零改动（`strategy_check` 守成对性）。
- 本轮再加一层：**接线路径可关可开**，且三层开关与 J4 记忆完全同口径 ⇒ 公网/本地演示/私有部署三种形态的差异是**声明出来的**，不是隐式假设。

### 3.5 维护状态
- **对标反面教材（台账复跑仍成立）**：OLV 13,901★ 自 2026-05-15 零推送；Loyal-Elephie 352★ 自 2025-02-28 零推送、0 CI。
- **心屿本轮实质动作**：`v1.4.0` 版本 + CHANGELOG 条目 + 厂商漂移机器可见（`--check-upstream --strict` 现在就能复现"我们落后 three r186"）。
- **仍缺**：贡献者仍集中 1 人（团队 5 人）；`docs/` 站未建（低优先）。

### 3.6 文档完善程度
- 台账 8/9（缺 `docs/`）。同体量参照里 opensoul(58★) 9/9、leemo 8/9 ⇒ 齐备度与星数无关的结论**复算仍成立**。
- 本轮把"对标数据"本身文档化成机器台账（前两轮是一次性文本），这是文档维度的实质增量。

### 3.7 适用场景
- 无翻牌：心屿（高校情绪倾诉 / 独居青年 / Web 免安装）与 A 层通用工作台、C 层论文原型场景不重叠；
  14 家里实现"医疗免责 + 危机转介 + 降级明示"三件套的仍是 **0 家**。
