# 用户试用反馈采集模板（佐证材料用）

> 用途：AIC「佐证材料」要求可含**用户反馈**。官方允许"用户反馈、试点应用证明"等。
> **红线：数据必须真实采集，严禁编造/代填**——伪造一经查实取消资格（官方规则"原创性与真实性"条）。
> 目标量：10–30 份即可显著抬升"应用价值"档位；重点是真实留痕，不是数量。

## 一、采集方式（任选其一或组合）

| 方式 | 做法 | 留痕物 |
|---|---|---|
| 问卷（推荐） | 发在线演示链接 + 下方问卷题目，回收导出 | 问卷导出截图/CSV |
| 试用截图 | 请使用者体验后发一张带情绪曲线/对话的截图（自愿，可打码） | 图片 + 日期 |
| 文字反馈 | 自由反馈 1–3 句 + 是否愿意署名 | 原文 |

## 二、问卷题目（约 2 分钟填完）

1. 你的身份：□ 在校学生 □ 其他
2. 你在什么场景下会想用它？（多选）□ 学业压力 □ 考试/答辩焦虑 □ 人际矛盾 □ 情感困扰 □ 只是随便聊聊
3. 它对你此刻情绪的判断准不准？□ 准 □ 大致准 □ 不准（可写一句实际输入与它的判断）
4. 它的回复有没有"接住你"？□ 有 □ 一般 □ 没有
5. 情绪曲线/星雾这些可视化，对你有意义吗？□ 有 □ 一般 □ 没有
6. 你最希望增加/改进的一点（开放题）：＿＿＿＿＿＿
7. 你愿意把它推荐给同学吗？□ 愿意 □ 看情况 □ 不愿意
8. （可选）昵称/匿名：＿＿＿＿　联系方式（仅用于回访核实，不对外提交）：＿＿＿＿

## 三、汇总表格式（合并进佐证材料 PDF 时使用）

| 编号 | 日期 | 身份 | 判断准确性(3) | 共情感(4) | 可视化(5) | 推荐(7) | 关键原话（节选，经本人同意） |
|---|---|---|---|---|---|---|---|
| U01 | 2026-10-__ | | | | | | |

## 四、佐证材料合并规范

- 官方要求：佐证材料**合并为一个 PDF** 提交；
- 建议结构：封面说明页 → 汇总表 → 问卷导出截图 → 试用截图（脱敏）→（如有）软著/其他证书；
- 涉及个人信息的部分：提交版只保留昵称与反馈内容，**联系方式不得出现在提交版**；
- 未采集到真实反馈前，方案与 PPT 中的口径保持"尚未开展真实用户试点"（当前口径已如此，勿提前改为"已有用户"）。
