## 一、官方原文（逐字）

> 6. 佐证材料：用于证明作品真实性、创新性与应用成效，可包括专利证书、软件著作权证书、论文录用/发表证明（首页）、企业合作意向书、用户反馈、试点应用证明等，**合并为一个 PDF 文件提交**。

要点：**只交一个 PDF**；报名系统的「佐证材料」栏目是单文件上传位。

## 三、合并顺序（官方只说合并，顺序由我们定）

1. 封面说明页（作品名 + 目录 + "以下材料均真实取得"声明）
2. 汇总表（`用户试用反馈采集模板.md` 第三节的表）
3. 用户反馈问卷导出截图 + 试用截图（**脱敏**）
4. 证书/证明类（软著、论文首页、合作意向书、检测报告等，有则放）
5. 无则留白说明页：**未取得的材料不补、不编造**，宁可少页。

## 四、红线（违反可能扣分或取消资格）

| 红线 | 说明 |
|---|---|
| 严禁编造数据 | 伪造佐证一经查实取消资格；未采集到真实反馈前，方案/PPT 口径保持「尚未开展真实用户试点」 |
| 禁出现校名 / Logo / 指导教师 | 官方公平性条款，适用于全部提交材料 |
| 提交版不得含联系方式 | 采集模板里的手机号/邮箱只用于回访核实，**不得进提交版 PDF** |
| 只交一个 PDF | 多文件会被视为材料不完整 |
