| 判定腿 | accuracy（非危机 231 条） | macro-F1（六类） | 危机召回 | 平均延迟 | 成本 | 离线可用 |
|---|---|---|---|---|---|---|

## 二、路由架构（当前上线）

```
输入 ─→ ① 危机词短路（确定性规则，不调任何模型）
          ├─ 命中 → crisis 拦截 + 热线转介
          └─ 未命中 ↓
        ② 词典扫描 + 本地模型推理（并行证据）
          ├─ 共识 → 双证据采信（词典读数）     ← 57/73 条走此路径
          └─ 分歧 → 词典裁决，分歧信号入证据链  ← 10/73 条
        ③ route=lexicon 模式下：分歧 → LLM 仲裁（既有语义保留，开关切换）
```

**结构性永不倒退保证**：共识与分歧的最终读数都是词典判定 → 73 条评测集上路由层 ≡ 词典基线
（2026-10-09 双口径实测：离线 98.6% / 在线 98.6%，`GET /api/emotion/eval` 可现场复跑）。

## 三、关键发现（域偏移的量化证据）

1. **两个基准的结论相反，揭示了域偏移**：
   - 73 条人工评测集（词典主场）：词典 98.6% >> 模型单腿 86.6%
   - 237 条盲测集（校园口语生成域）：模型 92.2% >> 词典 46.3%
   - 解释：词典按情绪词面匹配，盲测中的口语化表达（无显式情绪词）大量失配；模型学到语义分布，在生成域鲁棒。
2. **在线分歧升 LLM 的否决实验**：分歧 10 条升 LLM 后 73 条在线 98.6% → 94.5%（LLM 错 4 条），故上线策略采用词典裁决，LLM 仲裁保留为 `route=lexicon` 可切换语义。
3. **词典危机词表盲区**：盲测 6 条危机改写句仅 2 条被词表命中（"想消失""撑不下去"等改写未覆盖）→ 已登记为后续 P0：扩充危机词表（安全层改进，不涉及模型）。
4. **延迟/成本三档**：词典 μs 级 / 模型 27ms（本机 GPU）/ LLM 647ms——三级路由以"共识快判"把 LLM 调用次数从 100% 降为 0（共识+分歧裁决语义下），演示可全程拔网线。

## 四、与竞赛评分维度的映射

- **技术实现**：自研微调（chinese-roberta-wwm-ext，3622 条混合语料：SMP2020-ECDT 公开底料映射 + DeepSeek 生成+self-consistency 过滤的校园域对抗样本）+ 三级路由 + 101 个 JUnit 用例（覆盖率 LINE 97%/BRANCH 95.2%）。
- **方案完整性**：训练/评测/路由全链路脚本可复现（`ml/data/build_dataset.py` → `ml/train_emotion.py` → `ml/server.py` → `_test/emotion_blindset_eval.py`）。
- **答辩演示杀手锏**：① `route` 开关现场切换两种路由策略对比证据标签；② 拔网线演示（模型腿离线可用，LLM 腿自动退出）；③ 「没什么好难过的」案例——模型判对而词典判错，分歧信号可见。
