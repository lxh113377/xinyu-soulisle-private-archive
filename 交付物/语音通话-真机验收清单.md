# 语音通话 · 真机验收清单（wb-echo-L2）

> 机器判据已过 23/23，但**麦克风+扬声器真回环本机无法自动验证** —— 这一栏只能你亲手做。
> 每条写清「怎么看 / 期望什么 / 不对说明什么」，5-8 分钟能走完。

## 准备

1. 起服务（工作目录必须是项目根，`./src/` 才解析得到）：
   ```
   java -jar server\target\soulisle-server.jar --server.port=8123
   ```
   浏览器开 `http://127.0.0.1:8123`，**允许麦克风**。注意：**用外放不要用耳机** —— 耳机挡住了回声，打断一定好使，测不出真问题。
2. 点右上角「语音通话」进入浮层（不支持的浏览器这个按钮会自动隐藏，见约束 1）。

## 验收项

| # | 怎么做 | 期望 | 不对说明 |
|---|---|---|---|
| A1 | 说一句完整的：「我今天被导师骂了，特别难受。」 | 自然停顿后它就回应，首声读数出现在状态条 | 收句面/上游问题，看字幕里送出去的那句对不对 |
| A2 | 说：「我最近老是失眠，然后——」（**故意用「然后」收尾**） | 约 1.1 秒内就回应（旧码要死等 1.9 秒） | 宽限窗没生效 |
| A3 | 它开口念到一半，你**直接插话**「不是这个意思」 | 念白**立刻停**（应在 0.2 秒内），字幕换成你的话，它跟着你的新话走 | 打不断 = 打断顺序还是旧的；或电平基线取错 |
| A4 | 连着打断 3 次，每次插不同的词 | 每次都停，且**下一句送模型的内容里不含上一轮的念白残句**（看字幕） | 残句串味 = 打断瞬间的偏移重置没生效 |
| A5 | 它念完后**你不说话**，安静 2 秒 | 它不该自己停在自己句子中间（不该被自己的念白打断） | 自打断 = 分层回声判的精确面闸失效（AEC 失效时的兜底） |
| A6 | 插话里带上情绪词：「我最近老是失眠，emo 得不行」 | 字幕里这几个词**没被听错**（浏览器给 5 个候选，词表重排会挑对的那条） | n-best 没接线，看 A6 对照：把下面这条也念一遍对比 |
| A6' | 同上，但故意念得含糊一点、离麦远一点 | 可能仍偶有错字 —— 这是浏览器引擎精度天花板 | 属预期；要根治只能换云 ASR（本轮已否决） |
| A7 | 点「可随时打断」切到「讲完再听」，再做一次 A3 | 它应当**念完才轮到你**（半双工语义，插话不算数） | 半双工开关失效 |
| A8 | 说话中途点静音麦克风，再点回来 | 立刻能重新说话，无残留、无需要刷新 | 静音键没复位 |
| A9 | 退出通话后点页面其他地方说话 | 不应再自己重启识别、不出字幕 | 退出态没复位（C9 已钉，真机复核手感） |

## 一句话判据

**A3 和 A4 是本轮的全部意义** —— A3 绿 = 顺序修对了，A4 绿 = 打断后不会串味。其余是回归面。

## 已知边界（不算 bug）

- 浏览器（Chrome/Edge）的 Web Speech 中文识别精度有天花板，近场、语速正常时最好；本轮能提升的是「n-best 重排 + 收句不再卡顿」，提不到「识别率翻倍」。要翻倍必须换云端流式 ASR。
- 不支持连续识别的浏览器会自动重启识别会话，这是真机语义，偶发一次重启属正常。
- 真机音质/音色由浏览器音色决定，本机神经引擎（sherpa-onnx sidecar）起在 `127.0.0.1:8320` 时才优先用它。
