## 2. 逐项差距说明

### 2.1 🔴 高｜7 个触控目标只有 27–35px（实测，已闭合）

✅ 复算（修前，4 视口 × `has_touch`）：`btn-lightshow 87×27`、`btn-dock 58×28`、`btn-settings 97×35`、
`btn-theme 67×35`、`btn-clear 108×35`、`btn-export 108×35`、`btn-demo-clear 72–91×27/42`。
对手里只有 6/12 家的 CSS 声明过 ≥44px 级别的目标，2/12 家按指针类型适配 ⇒
**这一维对手也普遍没做**，但我们的场景（手机打开、五幕叙事靠滚动、底部对话坞靠点）
决定"别人没做"不构成豁免理由。
修法：`@media (pointer:coarse)` 块，统一 `min-height/min-width:44px`。
**为什么不用宽度断点**：需要大目标的是**手指**不是**窄屏** —— 平板横屏 768px 用触摸时，
`max-width` 断点不会触发，缺陷照旧；而桌面 fine pointer 不该被撑大（会改首屏观感与像素标定）。

### 2.2 🔴 高｜输入框 14–15px，iOS 聚焦会自己放大整页（实测，已闭合）

✅ 复算：`chat-input 15px`、`set-provider 14px`、`set-base/key/model 15px`。
iOS Safari 对 <16px 的输入控件聚焦时强制放大视口，用户被横向推走且看不到自己输入的内容。
修后四档视口全部 ≥16px。

### 2.3 🟡 中｜三条"有 meta 但主动禁缩放"的对手是可借鉴的反面教材

3/12 家用 `user-scalable=no` 或 `maximum-scale=1` 换"像原生 App"。这是**主动牺牲低视力用户**的决策。
我方判据 M4 把它钉成红线（含 `maximum-scale=1` 这种同义写法），并对 `maximum-scale=5` 明确不判 ——
防止判据过度收紧成"禁止任何缩放上限"。

### 2.4 🟢 低｜横向溢出这一维我们本来就赢

320/360/390/768 四档 `scrollWidth == clientWidth`，零溢出。如实记，不改判据也不借它抬高总分。

## 3. 本轮我自己被抓到的（六条，全部一手实测）

1. **探针没开触摸仿真 ⇒ 改完 CSS 数字一动不动**。`(pointer:coarse)` 只在 `has_touch=True` 的上下文匹配；
   首版 `new_page(viewport=..., device_scale_factor=2)` 没开 ⇒ 我几乎把"生效了"判成"改错了"。
   判据因此把这条写进注释与 selftest 前置。
2. **我把 CSS 标准引错了**：首版写"44×44 = WCAG 2.5.8 的要求"。实际 **2.5.8 的 AA 底线是 24×24**，
   44 来自 iOS HIG / Material（WCAG 中对应 **2.5.5 AAA**）。真跑顺手又暴露我把原生 checkbox 的 13px
   一刀切判红。现改双层口径：24 为硬底线、44 为本仓对**独占型控件**自选并钉住的红线，
   `label` 内 checkbox/radio 按**等效控件**豁免（label 自身 <24 时豁免不成立），
   且**豁免个数打印在 PASS 行里**，不静默。
3. **裸 `input{font-size:16px}` 抢不过基线**：基线 `input[type=text]{font-size:15px}` 特异度 (0,1,1)，
   我那条是 (0,0,1) ⇒ 首版改完实测仍 15px，**只有 checkbox 变 16px**（它没被类型规则盖）。
   半生效比不生效更坑：不查就以为修完了。
4. **`css_largest` 名不副实**：按路径深度取，实际抓到的是最浅的小文件而非最大的样式表 ⇒
   `mq=0` 那批读数不可信。改为按 tree 的 blob `size` 取，并补边界 D 反例钉住。
5. **臆造后缀面**：`\.cssx?` 匹配不到真实 CSS（`.cssx` 不存在），且让"没 CSS"与"0 条媒体查询"混同。
6. **拿顺序冒充语义**：非 Web 仓（letta / chibi / MoodChat / Loyal-Elephie）本该判"范围外"，
   却因我自己把 `css:NA` 塞进 `errs`，被第一条 `if err` 抢先判成"取数失败" ⇒ NA 从 2 虚增到 5。
   现范围判定前置，恒等式按轴成立。
   另：`tail` 之后的 `rc=0` 是管道的退出码不是探针的（探针有 NA 应为 1）—— 老规矩，不再据此下结论。
