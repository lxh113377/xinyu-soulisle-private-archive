## 2. 逐项差距说明（本轮四条，全部是"看的人/物自己出了问题"）

- **G1（本轮最硬）`hook_wiring` 判据被"解释器吃哪种路径形态"绊倒，红因却写成"钩子坏了"。**
  `shutil.which("sh")` 实测 **None** ⇒ 回退命中 `C:\Windows\system32\bash.EXE`（**WSL 启动器**）⇒
  它不吃 `C:\...`（反斜杠被当转义吃掉 ⇒ 实参变 `C:Users37533...`）⇒ `sh -n` rc=127 ⇒
  W1 判红，并把 selftest ⑪（删件须 rc=1）⑫（复原须 0/2）一起带红 ⇒ `2/12 未过`。
  **辨别点**：W2 当场显示副本 == 源（sha=`b0403aeb2a60`）⇒ 钩子没坏；且 **05:13 那次电池同一份代码是 PASS**
  ⇒ 是环境在两次之间漂了，不是本轮提交引入的红。**处置**：优先 Git 自带 bash（吃 Windows 路径），
  只剩 WSL 时转 `/mnt/<盘符>/...`；**判据一条没放宽**（解析不过仍旧判红），并补 ⑬⑭⑮ 三条自证（12→**15 腿**）。
