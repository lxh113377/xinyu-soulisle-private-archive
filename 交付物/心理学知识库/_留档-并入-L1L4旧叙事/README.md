# 心理学知识库 — 机制说明（README）

> 定位：心屿 MindIsle（AI 情感陪伴）背后的心理学专项知识库。
> 通过多轮迭代对话持续扩充：覆盖权威学术文献、经典理论著作、前沿研究成果。
> 每轮对话的回复末尾固定附「本轮知识整合进展」板块，本目录同步更新。

---

## 一、置信度分级标准（所有条目强制标注）

| 等级 | 含义 | 判定标准 | 使用规则 |
|---|---|---|---|
| **L1 实证强** | 实证结论 | 多项独立实验或元分析支持，效应量与边界条件清楚 | 可作为工程/结论依据 |
| **L2 理论/证据混合** | 理论观点 | 权威学者提出的框架，有支持证据但存在争议、边界不清或复现不佳 | 可作参考框架，引用时须同时标注争议 |
| **L3 推测/初步** | 推测性内容 | 假说、初步证据、跨领域外推、单一研究 | 只能作为探索方向，禁作依据 |
| **L4 无依据** | — | 无可溯源出处的主观断言 | **禁止写入、禁止输出** |

### 溯源规范
- 每条关键论述必须标注：作者 + 年份 + 出处（期刊/出版社/DOI 或可检索信息）。
- 转引须注明"转引自"；无法确认出处的，降级为 L3 并标注"待核"。
- 对经典结论的**现代争议必须如实记录**（见 01 号文件对 Ekman 普遍性、Schachter-Singer 复现问题的处理范式）。

## 二、迭代规则
1. **每轮必有进展**：每轮对话至少新增/修订 1 个知识条目，并更新 `00-索引.md` 与 `整合日志.md`。
2. **条目三要素**：知识陈述 + 来源标注 + 置信度分级；与心屿工程的相关性单列「工程关联」。
3. **争议必录**：任何被后续研究质疑的经典结论，须在同一条目内记录"争议现状"，不得只写教科书结论。
4. **单文件主题化**：一个文件一个主题域，超过 ~300 行拆分（part1/part2…），与项目 memory 同规。

## 三、目录结构
```
心理学知识库/
├── README.md              # 本文件：机制与标准
├── 00-索引.md             # 全部条目索引（主题 × 置信度）
├── 01-情绪分类学与基础理论.md   # 第一轮：七类情绪的学术谱系与映射
├── 整合日志.md            # 每轮整合进展（append-only）
└── （后续主题按序编号）
```

## 四、安全边界
- 本知识库是**学术参考资料**，供项目研发使用；危机干预相关内容只记录学术来源与设计原则，**不构成给终端用户的操作手册**，不提供具体量表施测指导。
- 心屿的危机信号链路（词表命中 → 最高优先级 → 转介）保持工程独立实现，知识库仅提供理论依据。
