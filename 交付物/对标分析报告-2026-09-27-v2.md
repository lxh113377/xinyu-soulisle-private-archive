## 2. 逐项差距说明（差距 → 归因 → 本轮处置 → 证据）

### 2.1 🔴 差距一：无障碍从来没有被判据盯过，而"0 违规"是一个假绿（本轮主修，已闭合）

| 环节 | 内容 |
|---|---|
| 现象 | 本轮第一版审计（`axe.run(document)` 不传 `runOnly`）返回 **violations = 0**，双视口 × 两动效偏好都是 0 ✅ 05:2x 实测 |
| 归因 | `label-content-name-mismatch` 在 axe 4.10.2 里挂 **`experimental` 标签**，默认集与"严格 wcag"集都不跑它。同页加 `experimental` 立刻命中 `serious:2` ✅（两种规则集对照见 §6 复现命令 3） |
| 二阶归因 | 更值得记的是**为什么会写成不传 runOnly**：因为"0 违规"是这条命令最省力的产出，而它同时是判据最没用的产出 |
| 参照 | 16 家只有 SillyTavern 把这个东西放到仓库里（`public/scripts/a11y.js`）；没有一家在 README 里承诺它 |
| 处置 | 常驻判据 `_test/a11y_check.py`：**规则集含 experimental + 6 状态 × 2 主题 + 正样本自证 + 像素级动效降档**，12 个审计单元违规节点数必须为 0 |
| 证据 | 修复前 `A11Y-FAIL … 违规节点=16 红状态=8 … 动效比=0.77 红在=A2,A7,A5b`；修复后 `A11Y-PASS 审计面=12项 违规节点=0 passes最小=18 动效降档=0.0倍 未验=0`（✅ 判红 05:36 / 转绿 05:39 两轮实跑，中间零改判据） |

**A1–A8 的分工写死在判据头部注释里**：A1 证"审计真落在填充后的 DOM 上"（每状态 `passes>0`），
A2 才是违规计数，A3 是**反例自证**（注入无名字按钮/无 alt 图/低对比文本/缺必填 ARIA 属性的 slider，
axe 必须抓到：实测抓到 5–6 类），A4 把"工具量不出的那一格"从沉默变成点名，
A5 用像素而不是 CSS 判动效降档，A6/A7/A8 分别管键盘焦点、语音控制、读屏播报。

### 2.2 🔴 差距二：`prefers-reduced-motion` 是空头承诺（已闭合，且是产品级缺陷）

| 环节 | 内容 |
|---|---|
| 现象 | `src/css/style.css:174` 确实有这条 media query，注释还写着「减弱动效用户关闭装饰动画与平滑滚动」；但它只关了 `.scroll-hint` 与 `.voice-btn.recording` 两个 CSS 动画 |
| 归因 | **主叙事动效在 WebGL 里**：`three-scene.js` 的 `tick()` 用 `performance.now()` 自走时钟驱动 `points.rotation` 与逐星闪烁，CSS 那一层管不到它 |
| 实测 | reduce 态三帧截图哈希全不同、平均像素差 0.0607，正常态 0.0470（✅ 05:2x 勘察）⇒ 开了"减弱动效"和没开的差别**测不出来**，比值 0.77 |
| 为什么这格要紧 | 本项目当前 0 项降级开关是"给评委演示用"的，但这个 media query 是操作系统给**前庭功能受损用户**的明确请求；写了注释没写实现，等于对用户许愿后不兑现（与「文档写了 ≠ 磁盘有」反向，同 M6） |
| 处置 | `three-scene.js` 读 `matchMedia("(prefers-reduced-motion: reduce)")`，命中则**冻结自走时钟**（`time = 0`）：星雾不再自转、不再自闪；镜头位移留在滚动通道上（那是用户自己发起的，属 WCAG 2.3.3 的豁免面，不是本开关要砍的对象） |
| 证据 | 修复后 normal=0.0516 / **reduce=0.0000 / 比值 0.000**（✅ 05:44）；A5a 同时断言"正常态必须真的在动"（0.0516>0.002），否则 A5b 是空判——**这一条是防止"把动画整体删掉来通过无障碍判据"这种作弊修法** |

### 2.3 🔴 差距三：语音控制用户按可见文字下指令，会点不到按钮（已闭合）

- 实测缺陷（axe `label-content-name-mismatch`，serious）：
  `#btn-settings` 可见文字「⚙ 模型设置」而无障碍名「设置」；`#btn-theme` 可见「☾ 深色」而无障碍名「切换深浅主题」。
  A7 用自己的口径又抓出**共 4 件**（另含两个纯图标按钮，属误伤，见 §7-3）。
- 后果不是抽象的：WCAG 2.5.3 要的是"说'点击 模型设置'时那个按钮就叫这个名字"。
  无障碍名取了个更短的别名，语音用户就点不到。
- 处置：图标改 `<span aria-hidden="true">` 与文字分离，无障碍名以**可见文字开头**并补语义
  （`模型设置` / `深色主题，点击切换`，随主题切换由 `apply()` 同步更新）；**未改判据口径**。
- 证据：A2 违规节点 16→0、A7 不匹配 2 件→0（✅ 判红 05:36 → 转绿 05:39）。

### 2.4 🟠 差距四：本项目自己也 0/16 那一边站（README 无障碍声明 = 0）

三通道跑 self 时，通道 B 我方同样 0 命中 —— 与 peers 一样"没承诺"。
r41 已经把 README 缺测试命令登记成过一条差距，本轮同族第二次撞上：**能力建好了，唯一被人读到的面没有它**（M6）。
处置：README 增加「无障碍」一节（写实测口径，不写形容词），并把它挂进 `docs/quality-gates.md` 的判据清单。

### 2.5 🟠 差距五：自动化看不见对比度的那一格（登记，未闭合）

- axe 在暗底 + 半透明卡片 + WebGL 背景的页面上对 **23 个文本节点返回 `incomplete`**（既不算过也不算违规），
  样本点名 `.brand`、`.brand-sub` ✅ 05:44 实测。
- 归因到机制：`rgba()` 卡片叠在 canvas 上，**有效背景色静态算不出**，工具只能弃权。
- 本轮处置：把弃权计数**钉成棘轮**（A4，`XINYU_A11Y_INC_MAX` 默认 30，超即红）并逐样本点名，
  使这一格从沉默变成每轮都印在收口行的数。**未做**像素级对比度实算（需要有效背景合成模型）⇒ 登记 P1（§5 中 2）。
