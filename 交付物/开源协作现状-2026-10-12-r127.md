## 三、发送门槛（满足任一即可发，届时一键成型）

1. **最小复现**：能在对方仓 `clone → 一条命令 → 看到失败`；报告体含：环境、命令、期望、实际、影响面。
2. 或 **PR 形态**：改动 ≤10 行 + 附本地跑过的证据 + 说明为何不动其它文件。
3. 或 **文档纠错**：对方文档与行为不符，附 `gh api` 取的原文行号。

命令形态（授权后照抄即可）：

```bash
gh issue create -R <owner>/<repo> --title "<一句话>（附最小复现）" --body-file <本仓写好的草稿.md>
```
