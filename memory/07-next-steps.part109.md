## ⑤ 本轮两件判据自检抓到的「本件自己的 bug」（可复用教训）

1. **`ci_contract_check.py`**：`any(s in x for x in (ci_scripts, bat_scripts))` 是在两个 **set** 上迭代，
   做的是「`s` 是否是这两个 set 的成员」⇒ 恒 `False` ⇒ **14 条合法 blocking 全被误报「没人跑」**。
   正解：集合先摊平成名字集合再查。**只有正例腿抓得到这类「尺恒假」缺陷**（变异体腿抓「尺恒真」，
   方向相反）—— 两类腿缺一不可。
2. **`peer_maintenance_probe.py`**：`strftime("%Y-%m-%dT%00:%00:%SZ")` 抛 `ValueError: Invalid format string`
   （`%00` 非合法指令）；模块 docstring 未加 `r` 前缀致 `\d` 触发 `SyntaxWarning`。
   教训：**Python 格式化串里 `%` 后必须是合法指令**，别照抄 shell 的 `%N` 补零写法。
