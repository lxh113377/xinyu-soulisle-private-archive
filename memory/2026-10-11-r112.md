## 本轮一手发现（四条，都是会再犯的）

1. **扩否定窗口必然引来误伤，动手前要先想清楚「什么不算否定」**。首跑就踩中 2 条跨标点误伤。
   与 r110「透明度不能用同一档治所有状态」同族：**全局参数改一处，先枚举它会波及的状态**。
2. **8123 上的旧 jar 会同时造成两个假象**：① 锁住 `target/*.jar` 使 `mvn package` 的 repackage 失败
   （`Unable to rename … to .original`）；② 不停它则双端一致必然**假红**（旧 Java 窗口=3 vs 新 JS 窗口=4）。
   取证（命令行=本仓 jar、启动 01:03:37、owner=37533）后停掉重打，新 jar 起在同端口。
3. **修仪器只消除今天的 4 条**。全池 AST 一扫还有 21 处裸抛栈点 ⇒ 必须立常驻棘轮（只降不升），
   否则下一件新写的判据照样再犯（这一族已是第二次出现）。
4. **手写的浏览器回退从不打印用的哪个引擎** ⇒ 「本地浏览器判据全绿」不可归因（CI 是 ubuntu + 受管 chromium）。
   收编时把「打印身份」做成硬性要求，而不只是消掉重复代码。
