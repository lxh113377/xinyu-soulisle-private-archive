### 本轮事故与自纠（三条）
1. **循环洗 rc**：`for c in ...; do o=$(...); r=$?; echo ...; done && git commit` —— 循环整体 rc = 最后一条 `echo` = 0，
   `size_budget` 的 rc=1 没拦住提交 ⇒ 提交面短暂带超预算，下一条提交 `ac7e85f` 修（预算按实测 +5% 重登记）。
   同族于「管道洗 rc」（R308），新增形态 = **循环末尾非判据命令的 rc 顶替判据 rc**；此后凡判据循环一律改用 FAIL 汇总变量。
2. **我自己编造了提交号**：CHANGELOG r130 段初稿把 FM/SC 的 hash 写成猜的 `1c9e3cc`/`1c1f2e8`，
   复算 `git log` 后按实际 `8730e14`/`cd2f3b2` 更正——写 hash 前必须 `git log` 现取，禁止凭印象。
3. **index 竞态第三次**（详见 r129 事故段与 `xinyu-shared-index-commit-discipline.md`）：本轮起已按
   「staged==意图集合断言」执行，其后各次提交均通过该断言。
