### ✅ anger 取舍 —— **老大 r103 已拍板走「保真怒」并已落地**

**决定**：anger 不再要求多区佐证（从 `need` 移出）+ `browDown` 权重 1.0→1.4、

**F12 实测（真 MediaPipe + face-api.js 真实照）**：
```
anger    0/2 → 2/2 (100%)   实得=anger
surprise 2/2   → 2/2 (100%)
```

**接受的代价（实测）**：专注轻皱 .40 → anger 0.41、说话+微皱 .30 → anger 0.33、
更轻的皱 .25 → calm（不误报）。⇒ 用户**专心思考、皱着眉头**时，星雾可能闪一下烦躁色。

**代价的三道防线**（防它从「闪一下」变成「骗人」）：
1. **F11 ②b 绝对分**：真愤怒 anger 分必须 **≥0.55**（当前 0.631）——
   离 calm 残余门槛 0.35 越近越危险；权重被压回 1.0（0.547）就判红。
2. **F11 ②b 强度序**：真愤怒必须比专注轻皱高 **≥0.10**（当前 0.221）。
3. **单测**：「专注轻皱会判 anger，但必须比真愤怒弱」。

**F11 反例6** 专门盯这次回退（把 `browDown` 压回 1.0 必须判红）——
首版写这条反例时**没抓到**：当时量的是「真怒−专注」的**差值**（回退后仍有 0.191，看着安全）。
改成量**绝对分**才抓住。⇒ **差值答「排得开吗」，绝对分才答「够不够压过平静」。**

**fear / sadness 仍保留多区要求**：它们吃 `browInnerUp`，而惊讶/担忧也吃 `browInnerUp`，

### Commons 那条路已实测证伪（不要再试第二遍）

| 尝试 | 实测结果 |
|---|---|
| `generator=search` 全文检索 5 类 | 13–56 候选/类，可用真实人脸**近乎为零**（画作/版画/书籍插页/猫/考拉/月亮） |

| 改用 face-api.js `test/images`（带标注、MIT） | **可用**：4/4 检出，surprise 2/2 判对 |

**结论**：公开域**情绪类**照片几乎都是「氛围/纪念」而非「表情瞬间」；
可用的是**表情识别项目自带的标注测试图**（face-api.js / fer / MediaPipe samples 仓库）。
后续扩类应直接去这些仓库找，别再走 Commons 分类树。

**仍缺**：sadness / fear / disgust / contempt 四类的真实标注照片（face-api.js 只有
angry/surprised 两张），以及**「专注/中性」这一类**的标注样本 ——
没有后者，anger 的取舍就只能靠上面的定性论证。
