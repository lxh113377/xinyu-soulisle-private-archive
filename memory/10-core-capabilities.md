## 一、为什么是这两项

产品差异点 = 「情绪识别 → 共情策略 → LLM → 可视化」闭环；**表情识别**（看得见的脸）与
**语意理解**（听得懂的话）是这个闭环的两个入口，任一退化，卖点即空转。评审口径（创新 30 /
技术 30）直接看这两项——它们是"套壳聊天产品没有"的部分。

## 二、机器面（唯一复算入口，每轮必跑）

```bash
python _test/core_capability_baseline_check.py            # 复算 + 棘轮对账
python _test/core_capability_baseline_check.py --selftest # 反例自证（4/4 可演习）
python _test/core_capability_baseline_check.py --update   # 更优读数写回基线（只升不降）
```

- 判红：准确率 / 危机召回 / 评测集条数 / 单测通过数任一低于基线，或表情单测出现 fail
- 环境未验（node 缺失等）⇒ rc=2，**不得当绿**
