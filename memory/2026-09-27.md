## 二、顺手还掉两条真实缺陷

### 1. `handoff.py help <在册命令>` 假阴性（我登记过、这轮自己修）
- 症状：`help trim-shell` / `volume` / `recycle` / `gate-diff` / `purge-guard` 全回 `ERROR: Unknown command`，
  而它们**都在分发表里**。上一轮我据此差点写成"处置指引指向死命令"。
- 根因不是漏登记，是**结构性的**：`print_help` 只查 `CMD_HELP` 一张手抄表，与分发表必然漂移。
- 修法定性：**派生不重复** —— 顶层帮助从 `USAGE` 现读、可分发命令从本文件源码现读分发表键，
  并加 `help --check` 覆盖判据（19 条命令 0 缺）。
- 变异证据：把 USAGE 里 `purge-guard` 行删掉 ⇒ 判据翻红并点名；还原 ⇒ 转绿。**先证明它会红**。
- 顺带修掉两个次生缺陷：① `Unknown command` 原来仍 exit 0（护栏把失败咽成成功）；
  ② 首版把索引写成模块级常量，`USAGE` 尚未绑定 ⇒ 导入即 `NameError`（跑一次就抓到，不是读代码抓到）。

### 2. 交付面「官方 9 项逐项齐全」原来只是人眼对照
- 新常驻判据 `_test/plan_pdf_coverage_check.py`：九项**从 `应用方案大纲.md` 现读**，页数 pypdf 实数（20 ≤ 20）。
- 第一次真跑就连续暴露**我自己的两个错**：
  ① 按整串相等匹配 ⇒ 把已在的两项报成缺失（大纲「目标用户与功能需求」↔ PDF「四、目标用户群体及功能需求」，
     同义不同字 = M5⑧"两把尺"）⇒ 改成「章节序号 + 词块重叠」；
  ② `extract_text` 用 `""` 连页 ⇒ 每页首行的章节标题被粘到上一行，**九章全部查无**，
     判据差点把完好的 PDF 报成"缺九章" ⇒ 改 `"\n"` 连接，并加"非锚定扫描"守卫：
     形状可疑只判 UNVERIFIED，**既不判缺也不判绿**。
- 自证九向（误伤 1 / 漏报 4 / 读空气 2 / 取数形状 2）。结论：九项覆盖**成立**，且从此有守卫。
