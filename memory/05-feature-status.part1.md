## 📋 计划中

- [x] **情绪点亮星雾**（2026-09-20，核心叙事）：初始全暗 = 极暗灰白微光轮廓；每句对话按其情绪点亮 1–8 颗星（强度越高越多），新点亮的会闪一下；历史持久化，刷新按记忆重放，一键清除即熄灭；次情绪另点亮 n/2 颗 → 一簇里出现两种颜色
- [x] **底部常驻对话坞**（2026-09-20）：第二幕探针 + 第三幕聊天融合为全局悬浮对话框，可折叠；点叙事区自动收起；标题条实时显示「已点亮 N 颗 · 记住 M 个瞬间」
- [x] **一键点亮（清屏 + 播放过程）**（2026-09-20）：① `body.showtime` 隐藏全部 UI，只留背景星雾；② 粒子熄灭 + 黑屏 1100ms；③ 沿半径由内向外逐颗有序点亮，六色各 180 颗（共 1080≈41%）→ 六圈色环，全程 ≈3.7s；④ **播完不自动跳回**，停在清屏画面滚动欣赏（Esc/点画面都不会中断）；⑤ 右下角「← 回到心屿（保留星雾）」只恢复 UI 并保留星雾，清空要再点坞里的「↺ 回到我的记忆」；**不写入记忆**
- [x] **立体厚盘粒子分布**（2026-09-20）：原薄螺旋盘在拉远视角时中心密成一坨 → 改为全空间极角 + 半径外扩的厚盘，配合按半径升序 `order[]`，点亮仍由内向外推进
- [x] **滚动驱动透明度**（2026-09-20，三轮调优）：叙事卡片随滚动淡入淡出 —— trigger 挂**面板自身**；**半透明为可见期常态**（0.3），仅逼近屏幕正中时短暂变实（1.0）；实测可见区间 `<0.6` 占 **64%**、极差 0.91；已移除 hover/focus 双态
- [x] 双色星雾（2026-09-20）— 沿螺旋 6 条交替色带做空间分离（径向渐变在加性混合下会糊成一色）；同色系次色经 `makeDistinct` 色相分离（≥100°）；次情绪须达主情绪 40% 权重，否则单色；探针 + 对话双路径接入（`EmotionEngine.secondaryOf`）；屏幕像素 2-means 验证：双色 0.522/0.384 vs 单色对照 0.088
- [x] 双路情绪识别 — 词典快判 + LLM 精判，分歧采信 LLM，路径在对话气泡明示
- [x] 危机信号拦截 — 命中即最高优先级，推送求助热线，星雾红色脉冲
- [x] 五幕滚动叙事 — 每幕一条可逆 scrub 时间轴（2026-09-19 修复回滚不可见）
- [x] 多轮上下文持久化 — localStorage `peiliao.history.v1`
